Help & contact

GOÄ billing on your Mac.

easygoae is a native app for Apple Silicon running macOS 14 or later. It manages patients, treatments, invoices and payments in a local library.

Currently in TEST mode. Generated documents are marked as test documents and are not requests for payment.

Start with a library

On first launch, create a blank library or import an existing invoices.sqlite library using the folder picker. Import makes a copy of the source; it does not synchronize libraries.

Create a complete backup

Open Settings and choose the complete SQLite backup. It includes patients, estimates, packages, stock, payments and cached PDFs. The legacy JSON export includes only part of the library.

Export PDFs and CSV files

PDFs and filtered invoice lists are exported after you choose a destination. Protect these files as carefully as the data inside the app.

Data after restarting

Normal launches retain the library, language and appearance. If data seems missing, first check that you are using the same app edition and macOS user account. Do not overwrite or delete the existing library.

Technical support

The support tracker is public. Describe the problem, app version, macOS version and steps to reproduce it. Use fictional examples. Do not send patient records, invoices, databases, bank details or screenshots containing personal information.
